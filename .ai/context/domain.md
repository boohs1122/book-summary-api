# 용어 정의

| 용어 | 의미 |
|---|---|
| 책 (Book) | 학습 대상 단위. 사용자가 제목을 직접 입력한다 |
| 회차 (Document) | 한 번의 촬영으로 만들어진 기록. 책 안에서 순번을 갖는다 |
| 요약 (Summary) | 회차 하나에 대한 구조화된 정리. 제목 + 핵심 항목 + 용어 |
| 핵심 항목 (keyPoint) | 요약을 구성하는 단위. heading + detail |
| 퀴즈 (Quiz) | 회차 하나에 대한 4지선다 문제 묶음. 회차당 1세트 고정 |
| 풀이 결과 (QuizResult) | 한 번의 응시 기록. 재응시하면 누적된다 |

## 관계

```
Book 1 ── N Document 1 ── 1 Summary
                       └─ 1 Quiz 1 ── N QuizResult
```

## 주의

- 문서 제목은 `Summary`의 `title`이 유일한 출처다. `Document`에 제목 컬럼이 없다
- 회차 순번(`sequence`)은 서버가 부여한다. 클라이언트가 계산하지 않는다
- 요약이 없는 회차(진행 중·실패)는 제목이 없으므로 원문 앞부분을 대체 표기한다
