# 테스트 규칙

전 구간을 덮지 않는다. 규칙이 있고 회귀가 발생하기 쉬운 지점에만 붙인다.

| 대상 | 이유 |
|---|---|
| LLM 응답 파싱·검증 | 스키마 위반, 항목 수 불일치 처리 분기 |
| 문항 수 산정 | 글자 수 구간 경계 |
| 텍스트 정제 | 공백·줄바꿈 정리, 하이픈 분철 결합 |
| 인증·소유권 | 토큰 실패와 다른 uid의 리소스 접근 거부 확인 |
| 네트워크 실패 | LLM 호출 실패·타임아웃이 작업 실패로 기록되는지 확인 |
| 비동기 작업 복구 | 실패 문서 보존과 재시도, 중복 작업 처리 확인 |
| 퀴즈 풀이 응답 | 채점 전 정답·해설이 응답에 포함되지 않는지 확인 |

LLM 호출 자체는 테스트에서 실제로 하지 않는다. 응답을 고정 데이터로 두고
파싱과 검증만 검증한다.
외부 인증·네트워크 호출은 가짜 응답으로 대체한다.
